# Contest entry draft

**Open Haggsfield — Turn AI generations into a film you can actually edit.**

The core model is MiniMax H3 through Comfy Cloud, with optional first-frame references. The product's focus is the work after generation: organize a film into shots, return each request as a recoverable take, compare alternatives, replace only a marked section, undo and export the sequence.

A private acceptance film exercised nine new image-anchored takes, durable job ownership, original-request recovery, private Supabase delivery, library return, comparison/replacement/undo, cloud save and restoration on the deployed origin, followed by a real hosted browser movie export. The project contains independent layers for footage, dialogue overlays and music. Provider charge estimates are kept distinct from verified invoices.

The public source includes setup instructions, MIT-licensed application code, sample illustrative stills and tests. Private screenplay material, production media, customer credentials and account/deployment state are excluded. A separate film/music license is not implied by the code license.

## Demonstration sequence

1. Open a project, show its scenes/shots, reference bin and generation settings.
2. Show the MiniMax workflow and cost quote before one explicitly authorized take.
3. Show the original job returning to private storage and arriving as an alternate take.
4. Compare, replace a six-second section, undo, then show the completed edit.
5. Save a private cloud checkpoint; restore it on the hosted app and export the movie.

The customer generation switch and hosted Stripe checkout remain gated. A test entitlement is not proof of payment. No claim of masked inpainting, frame-accurate mastering, synchronized campaign versions or Open Weights Only eligibility is made. A demo recording and formal contest submission still need to be prepared; this document is not a submission receipt.
